# sRNA_analysis_TYMV
Scripts for downstream sRNA Analysis against Arabidopsis TAIR10 and TYMV -S/-M SNP-masked genome.

These custom scripts for counting sRNAs at different chromosomes and calculating the 5' nucleotide content were developed with the assistance of ChatGPT (OpenAI, GPT-5.6 Sol). 
All scripts were manually reviewed, tested, and validated by the authors.
